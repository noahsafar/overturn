# Sales / customer-development kit

Everything you need to land your first pilot. Order to use:

1. **`icp.md`** — Who you're hunting and how you'll know one when you see it.
2. **`lead-research.md`** — Where to find them (free public sources + Yale network).
3. **`leads.csv`** — CRM template — paste names here as you find them.
4. **`outreach-cold-email.md`** — Three email variants. Pick one per persona.
5. **`outreach-linkedin.md`** — LinkedIn DM variant for the same personas.
6. **`discovery-call-script.md`** — 30-min agenda + the 20 questions from the master plan.
7. **`objection-handling.md`** — Pre-drafted answers to the seven objections you'll hear most.
8. **`followup-templates.md`** — Post-call thank-you, second-touch, pilot pitch.
9. **`pilot-agreement-draft.md`** — Starter 2-page agreement. **NOT LAWYER-REVIEWED — do not send to a customer until a healthcare attorney has signed off.**

## How to use this in week 1

- Day 1 (today): read `icp.md` + `lead-research.md`. Spend 90 min building 30 leads in `leads.csv`.
- Day 2: send 15 cold emails using the variant that matches each persona. Send 10 LinkedIn DMs to the rest.
- Day 3-5: follow up using `followup-templates.md` template 2.
- Day 6-7: take any discovery calls that landed. Run the `discovery-call-script.md` flow.

Goal: 3 booked discovery calls by end of week. 1 pilot signed by end of week 3.
